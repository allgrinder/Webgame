# Spieleentwicklungs-Skills

Quelle: https://github.com/gamedev-skills/awesome-gamedev-agent-skills (Commit c6ca6c41c839b68319ffc08430b99ab768debc32),
Lizenz Apache-2.0 (`GAMEDEV-SKILLS-LICENSE.txt`, `GAMEDEV-SKILLS-NOTICE.txt`). Unverändert übernommen, ohne `agents/`-Ordner.

Auswahl für dieses Projekt (PixiJS, Browser): `router`, `pixijs-rendering`, die engine-unabhängigen Disziplinen,
die Genres `survival-crafting` und `tower-defense` sowie `game-docs`. Nicht übernommen: Skills für Godot, Unity,
Unreal, Ebitengine, Phaser, three.js, Bevy, LÖVE, pygame, Defold, Roblox, die übrigen Genres und Workflows sowie
`create-game-assets` (setzt auf generierte oder fremde Grafiken; hier gilt: Grafik nur aus Blender-Skripten).

Die Projektregeln in `CLAUDE.md` haben immer Vorrang vor diesen Skills.
