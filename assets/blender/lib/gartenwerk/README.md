# Übernommen aus Gartenwerk

`gw_lib.py`, `gw_plants.py` und `gw_ground.py` stammen aus dem eigenen Projekt Gartenwerk
(Repository `allgrinder/Greenlabv2`, `assets/blender/lib.py`, `plants.py`, `ground.py`).
Sie werden hier als Bibliothek genutzt (Pflanzen-, Gras- und Kieselgeneratoren) und nur bei Bedarf
für Blender 4.0 angepasst. Eisenwerk-eigene Modelle in `assets/blender/models/` rufen sie auf und
setzen Maßstab (1 Feld = 1 m), Kamera und Farbgebung selbst.
